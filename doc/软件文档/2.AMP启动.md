# AMP 启动
## 刷写 Nor Flash

[参考链接](https://www.waveshare.net/wiki/%E6%A8%A1%E6%9D%BF:VisionFive2_Flash)

**主机流程：** 配置启动tftp服务器
```bash
# 更新文件
sudo cp /home/xikao/VisionFive2_6.6/work/u-boot-amp-spl.bin.normal.out \
        /home/xikao/VisionFive2_6.6/work/visionfive2_fw_payload_amp.img \
        /home/xikao/VisionFive2_6.6/work/amp/image.fit \
        /srv/tftp/
sudo chown -R tftp:tftp /srv/tftp
```

**板端流程如下：** 先拨码，再刷写Nor Flash，然后借助 tftp 进行主机启动
```bash
# ------ 刷写 Nor Flash ------ 
# 网线要插对，6.6 好像必须使用eth0
setenv ipaddr 192.168.5.9     # 板端IP
setenv serverip 192.168.5.11  # 主机IP
ping 192.168.5.11

# 方式一：
sf probe
sf erase 0x0 0x600000    # 一定要先擦除
tftpboot ${loadaddr} u-boot-amp-spl.bin.normal.out
sf write ${loadaddr} 0x0 ${filesize}
tftpboot ${loadaddr} visionfive2_fw_payload_amp.img
sf write ${loadaddr} 0x100000 ${filesize}

# 方式二：
sf probe
tftpboot 0xa0000000 u-boot-amp-spl.bin.normal.out
sf update 0xa0000000 0x0 $filesize
tftpboot 0xa0000000 visionfive2_fw_payload_amp.img
sf update 0xa0000000 0x100000 $filesize

# 验证
sf read ${loadaddr} 0x0 0x40000
md.b ${loadaddr} 8        # 应看到 SPL 头部魔数，不是全 F 或乱码
sf read ${loadaddr} 0x100000 0x40000
md.b ${loadaddr} 8        # fw_payload 头部同理


# ------ 刷写 image.fit ------ 
setenv ipaddr 192.168.5.9
setenv serverip 192.168.5.11
saveenv
tftpboot ${loadaddr} image.fit
bootm ${loadaddr}
```

**测试 AMP：** 主机启动方式成功
```bash
ip addr show
# 设置 IP 地址
sudo ip addr add 192.168.5.9/24 dev end1
```

**刷写到SD卡中启动：** 成功
```bash
# 板上 Linux：
sudo mount /dev/sdb4 /mnt       
sudo cp /home/xikao/VisionFive2_6.6/work/amp/image.fit /mnt/        
sudo cp /home/xikao/VisionFive2_6.6/conf/jh7110_uEnv.txt /home/xikao/VisionFive2_6.6/conf/vf2_uEnv.txt  /mnt     
sync
sudo umount /mnt

mmc list  # NOR 启动下 SD 卡通常是 mmc 1（mmc 0 = eMMC）
mmc dev 1
mmc info  # 应显示容量 119.2G 的卡
setenv bootcmd 'ext4load mmc 1:4 ${loadaddr} /image.fit; bootm ${loadaddr}'
saveenv

reset  # 上电自动从 SD 的 ext4 分区读 image.fit 启动
```

**官方 distro boot：**（完全自动，但要求卡上文件齐全）
VisionFive2 U-Boot 编译时就带了 distro boot（starfive-visionfive2.h 里 distro_boot_env），默认 bootcmd 会按 bootmode（拨码位）自动扫 SD/eMMC/NVMe
```bash
# 分区文件内容如下
sdb3 (vfat):  starfiveu.fit(image.fit 改名) + vf2_uEnv.txt + jh7110_uEnv.txt
# 文件路径如下：conf/jh7110_uEnv.txt conf/vf2_uEnv.txt 

# 但是要扩sdb3，否则放不下image.fit
```

**一般的固件镜像分区布局：**

| 分区 | 大小 | 文件系统 | 内容 | 谁读它 |
| :--- | :--- | :--- | :--- | :--- |
| `sdb1` | 2M | 裸数据 | U-Boot SPL（第一级引导） | JH7110 ROM（SD 启动时直接读） |
| `sdb2` | 4M | 裸数据 | `fw_payload` = OpenSBI + U-Boot（你卡上这个是普通版，不是 AMP 的） | SPL 读取并跳到它执行 |
| `sdb3` | 100M | `vfat` | boot 镜像：`starfiveu.fit`（= `image.fit`）+ `uEnv.txt` + dtbs | U-Boot 启动时加载内核 |
| `sdb4` | 2G | `ext4` | Linux 根文件系统 | Linux 挂载为 `/` |
