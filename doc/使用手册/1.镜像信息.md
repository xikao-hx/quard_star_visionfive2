# 镜像信息

## 统一打包

发布后的镜像按类型存放：

- 普通镜像：`work/target/normal/`
- AMP 镜像：`work/target/amp/`

可以通过 SDK 入口选择发布集合：

```bash
./build.sh sdk build normal
./build.sh sdk build amp
./build.sh sdk build all
```

```bash
./build.sh sdk build amp

./build.sh package \
  --rollback-index 10204 \
  --session-id ota-step2-20261004-001 \
  --target-bank b \
  --include-stage2
```

## SDK使用

**AMP 主要产物：**

| 文件 | 用途 |
| --- | --- |
| `work/u-boot-amp-spl.bin.normal.out` | AMP SPL，写入 SPI NOR `0x0` |
| `work/visionfive2_fw_payload_amp.img` | OpenSBI + U-Boot + RTOS，写入 SPI NOR `0x100000` |
| `work/amp/image.fit` | AMP Linux 内核、DTB 和 initramfs |
| `work/amp/amp_rtos.bin` | 本次构建选中的 RTOS 原始固件 |

**编译和打包：**

```bash
# 编译出所有镜像
RTOS=rtthread ./script/build-rtthread-amp-sdk.sh

# 普通版本
make -j$(nproc)
# work/image.fit
# work/visionfive2_fw_payload.img
# work/u-boot-spl.bin.normal.out

# 生成amp镜像
make amp-clean
make ampuboot_fit  RTOS=freertos -j$(nproc)
make ampfit  RTOS=freertos -j$(nproc)
# work/amp/image.fit
# work/visionfive2_fw_payload_amp.img
# work/u-boot-amp-spl.bin.normal.out

# 编译文件系统镜像
make buildroot_rootfs -j$(nproc)
# work/buildroot_rootfs/images/rootfs.ext4

# 打包出sd卡镜像
make amp_img
# work/sdcard_amp.img

make img
# work/sdcard.img
```

### AMP 启动

**SD 卡 + Nor Flash 镜像信息：**

* Nor Flash 镜像

| 物理区域 | 起始地址 | 结束地址 | 大小 | 用途 |
| --- | ---: | ---: | ---: | --- |
| `spl_a` | `0x000000` | `0x03FFFF` | 256 KiB | BootROM 固定加载的主 SPL |
| `spl_b` | `0x040000` | `0x07FFFF` | 256 KiB | SPL 备份和恢复源 |
| `gpt` | `0x080000` | `0x0BFFFF` | 256 KiB | 重定位 GPT 元数据 |
| `recovery` | `0x0C0000` | `0x0FFFFF` | 256 KiB | OTA 状态、bank 选择和掉电恢复信息 |
| `fw_payload_a` | `0x100000` | `0x6FFFFF` | 6 MiB | A bank OpenSBI + U-Boot + FreeRTOS FIT |
| `fw_payload_b` | `0x700000` | `0xCFFFFF` | 6 MiB | B bank OpenSBI + U-Boot + FreeRTOS FIT |
| 保留区域 | `0xD00000` | `0xFFFFFF` | 3 MiB | 未来扩容，当前不承载业务语义 |

* fw_payload 镜像内部布局

| 内部区域 | `fw_payload.bin` 起始偏移 | 加载后的源地址 | 大小 | 最终运行地址 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `OpenSBI` 及对齐空间 | `0x000000` | `0x40000000` | `0x200000`（2 MiB） | `0x40000000` | `OpenSBI` 固件和 payload 对齐空间 |
| `U-Boot proper` 及填充 | `0x200000` | `0x40200000` | `0x330000`（3.1875 MiB） | `0x40200000` | `U-Boot proper`；实际 `U-Boot` 后面补零到固定大小 |
| `FreeRTOS` | `0x530000` | `0x40530000` | `trusted_fw.bin` 实际大小 | `0x6E800000` | `SPL` 复制到 RTOS 运行区，`OpenSBI` 启动 `hart4` 执行 |
| `FreeRTOS` 保留运行区 | 不属于 payload 固定空间 | 不适用 | `0x800000`（8 MiB） | `0x6E800000`～`0x6EFFFFFF` | `FreeRTOS` 代码、数据、BSS、堆和栈 |

* SD卡镜像信息

| OTA 逻辑分区 | 默认设备 | payload | 写入方式 |
| --- | --- | --- | --- |
| `boot_a` | `/dev/mmcblk1p3` | `work/target/amp/starfive-visionfive2-vfat.part` | 从 offset 0 原始写 FAT 镜像 |
| `rootfs_a` | `/dev/mmcblk1p4` | `work/target/amp/rootfs.ext4` | 从 offset 0 原始写块设备 |
| `boot_b` | `/dev/mmcblk1p5` | `work/target/amp/starfive-visionfive2-vfat.part` | 从 offset 0 原始写 FAT 镜像 |
| `rootfs_b` | `/dev/mmcblk1p6` | `work/target/amp/rootfs.ext4` | 从 offset 0 原始写块设备 |

```bash
# work/amp/image.fit
# work/visionfive2_fw_payload_amp.img
# work/u-boot-amp-spl.bin.normal.out
# work/buildroot_rootfs/images/rootfs.ext4

make ampuboot_fit  RTOS=freertos -j$(nproc)
make ampfit  RTOS=freertos -j$(nproc)
make buildroot_rootfs -j$(nproc)

# Nor Flash
spl_a          256 KiB
spl_b          256 KiB
gpt            256 KiB
recovery       256 KiB
fw_payload_a     6 MiB
fw_payload_b     6 MiB
reserved         3 MiB

# SD 卡
├─sdb1      2M 
├─sdb2      4M  
├─sdb3      100M 
├─sdb4      2G 
├─sdb5      100M 
└─sdb6      2G
```
