# OTA升级

**前序准备：**

```bash
# 生成包
./build.sh package \
  --rollback-index 10204 \
  --session-id ota-step2-20261004-001 \
  --target-bank b \
  --include-stage2

# 拷贝到 userdata 分区
rm -rf /userdata/ota/ota-step2-20261004-001
cp -a /mnt/ota_package \
  /userdata/ota/ota-step2-20261004-001
sync

# 安装驱动，创建符号链接
cd /mnt/ota
./ota-test.sh
./create_link.sh
```

**ota_info：**

```bash
ota_info dump-state
ota_info read current_bank
ota_info read target_bank
ota_info read usable_bank
ota_info read ota_state
ota_info write target_bank <a|b>
ota_info write usable_bank <a|b|ab>
ota_info reset
ota_info sync
ota_info repair
ota_info flash <file> <partition>
```

**ota_package：**

```bash
PKG=/userdata/ota/ota-step2-20261004-001
PUBKEY=/etc/ota/keys/ota_public.pem
ota_package verify_stage1     "$PKG"     "$PUBKEY"
ota_package apply_stage1      "$PKG"     "$PUBKEY"
ota_package commit_stage1     "$PKG"     "$PUBKEY"
reboot -f
ota_package verify_stage2     "$PKG"     "$PUBKEY"
ota_package apply_stage2      "$PKG"     "$PUBKEY"
ota_package commit_stage2     "$PKG"     "$PUBKEY"
reboot -f
ota_package boot_success "$PKG" "$PUBKEY"   # complete

ota_info dump-state
```
